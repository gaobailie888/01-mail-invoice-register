# 飞书文稿与当前 Skill 功能核对

核对对象：飞书《机构号P7. 批量导入发票》的初稿、终稿可见部分，以及本 Skill 当前源码。

## 已实现并可直接表达

- 从邮箱按日期和关键词查找发票附件。
- 下载附件到本地并保留邮件来源。
- 批量处理一个本地文件夹中的发票附件。
- 提取发票号码、开票日期、购方/销方名称、价税合计、合计金额、税额。
- 从常见文本版式中尝试拆出项目明细。
- 生成 Excel：发票汇总、项目明细、处理日志三个工作表。
- 标记字段缺失、扫描 PDF、非 PDF 文件、金额差异和重复发票号码。
- 邮箱以只读方式打开，不发送、删除、移动或标记邮件。

## 文稿中需要修正或补充限定

1. “标准 Excel 包含两个工作表”已过时：当前版本有三个工作表，新增处理日志。
2. “金额识别为 0 可以筛出”不应作为确定功能表述。当前规则会标记金额字段缺失或价税合计与金额、税额不一致，但不会仅因金额等于 0 自动判异常。
3. “混入订单详情或行程单等非发票文件都可快速筛选”需要谨慎。当前 Skill 主要依赖邮件关键词、附件名、扩展名和发票字段完整性；不能保证识别所有伪装成 PDF 的非发票文件。
4. “199 张发票、256 条明细、约 5 分钟”是用户确认的真实实测数据，但自动化测试没有复现这批真实样本。发布时应标注为特定测试样本结果，并说明受邮箱、网络、PDF 版式和设备影响。
5. “一张包含多个项目都会拆明细”需要改为“对可识别的文本版式尝试拆出项目明细”。扫描件和特殊版式仍需人工处理。
6. “节省半天”可以作为这次样本的前后对比，不应承诺所有用户都能稳定节省同等时间。
7. “任何模型都能调用”不准确；应说任何支持 Skill、本地脚本执行并获得必要权限的 Agent 可以使用。

## 推荐对外口径

> 你可以让它直接从邮箱只读筛选发票，也可以把已经下载好的 PDF 放进一个文件夹。它会批量提取可识别字段，生成发票汇总、项目明细和处理日志；识别失败、重复或校验异常的记录不会被猜测填充，而会留给人集中核对。
