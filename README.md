# 📮 邮箱发票自动登记

把散落在邮箱或文件夹里的发票，整理成一份清晰、可追溯的 Excel 登记表。

不用逐封下载、逐张录入。你只需选择发票来源、先看预览、确认后开始处理。✨

## 它能帮你做什么？

- 📥 从指定邮箱文件夹或电脑本地文件夹中查找发票附件
- 📊 自动生成 Excel 登记表，便于核对、报销或交给财务
- 🗂️ 可选按购方公司整理原始附件，并生成各公司的分表和汇总
- 🔎 标记重复、信息不完整或无法识别的文件，交给人工确认

> 适合处理带文字内容的电子发票 PDF。扫描件、OFD、XML、图片、压缩包和加密文件不会被强行猜测，会保留并标为“待人工处理”。

## 三步开始使用 🚀

### Windows 用户

1. 从 GitHub 下载并解压本项目。
2. 双击 `start-windows.bat`。
3. 浏览器会自动打开本机向导，按页面提示完成即可。

### Mac / Linux 用户

在项目文件夹中运行：

```bash
python start.py
```

首次运行会自动准备所需组件。向导只在你的电脑上打开，不会向外网开放。

## 在向导中怎么操作？

1. **选择来源**
   - **邮箱模式**：从指定邮箱文件夹中寻找发票附件。
   - **本地文件夹模式**：整理你已经下载到电脑里的发票 PDF，不需要邮箱账号。
2. **先看预览**：确认日期范围、文件夹和找到的附件数量是否正确。
3. **确认执行**：预览无误后再开始生成登记表。
4. **查看结果**：打开生成的 Excel，重点查看“待人工处理”“疑似重复”和“购方未分类”等标记。

如果需要，可以勾选：

- “按购方公司整理原件”
- “生成购方分表与金额汇总”

## 使用前准备 ✅

| 你的使用方式 | 需要准备什么 |
| --- | --- |
| 整理本地文件 | 一个放有发票附件的本地文件夹 |
| 从邮箱查找 | 支持 IMAP 的邮箱、已开启 IMAP 功能、应用专用密码 |
| 保存结果 | 一个用于保存附件和 Excel 的本地文件夹 |

常见邮箱（QQ、163、Gmail、Outlook / Microsoft 365）可直接选择预设；企业邮箱请选择“自定义”。邮箱的 IMAP 开启方式和应用专用密码规则会变化，请以该邮箱官方帮助为准。

> 🔐 请使用“应用专用密码”，不要使用网页登录密码，也不要把任何密码发到聊天、截图或 GitHub。

## 你的数据安全吗？

- 邮箱只读访问：不会发送、删除、移动、星标或修改邮件状态。
- 密码只用于当前运行：不会写入 Excel、运行摘要或日志。
- 第一次正式处理前一定会先预览，由你决定是否继续。
- 页面不使用统计代码或第三方前端资源，只在本机 `localhost` 上运行。
- 重复发票默认保留并标记；程序不会替你做最终入账或税务判断。

> 任何本地程序都无法抵御已被恶意软件控制的电脑。企业使用时，请同时遵守本单位的邮箱权限、票据留存和数据合规要求。

## 处理完成后会得到什么？

在你选择的输出文件夹中，会看到：

- `attachments/`：找到的原始发票相关附件
- `AI邮箱发票登记YYYYMMDD.xlsx`：主要登记表
- `run-summary.json`：不含密码的处理结果统计

Excel 默认包含三张表：

1. **发票汇总**：发票号码、日期、金额、购销方、来源和处理状态
2. **项目明细**：可识别的商品或服务项目
3. **处理日志**：每个附件的来源、处理结果及失败原因

如果启用了购方整理，还会额外生成：

- `by_company/`：按购方公司归档的附件副本
- `*_购方分表.xlsx`：各公司的独立分表和汇总
- `buyer-summary.json`：购方分类与重复副本统计

## 关于重复发票与人工确认 🧾

为了避免漏掉重要文件，本工具采用保守规则：

- 只有文件内容完全相同的副本，才会被建议不计入合计。
- 发票号码相同但内容不同、号码缺失或购方不明的记录，都会保留。
- 无法判断的信息会提示你人工确认，不会自动认定“不能报销”或“不入账”。

本工具用于整理和初步核对，**不代替财务审核、报销审批、税务判断或最终入账**。

## 需要按公司分类？

可以把 `rules/buyer-rules.example.json` 复制到项目文件夹以外的私有位置，再根据实际公司名称修改，然后在向导中选择它。

⚠️ 真实分类规则可能包含公司或业务信息，请不要上传到 GitHub。

## 给熟悉命令行的用户

```bash
python scripts/download_and_register.py \
  --config /secure/invoice-mail.env \
  --since 2026-08-01 \
  --until 2026-08-31 \
  --output-dir ./invoice-output \
  --dry-run
```

先保留 `--dry-run` 查看预览；确认无误后移除它再正式执行。详细配置说明见 [`references/configuration.md`](references/configuration.md)。
