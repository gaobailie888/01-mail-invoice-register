# 邮箱发票自动登记 Skill

从邮箱或本地文件夹批量读取发票附件，解析可读的增值税电子发票 PDF，生成可追溯的 Excel 登记表；还可按购方公司整理原件，并生成购方分表与金额汇总。

## 最简单的用法

### Windows

1. 从 GitHub 下载并解压本项目。
2. 双击 `start-windows.bat`。
3. 浏览器会打开一个仅在本机运行的配置向导。
4. 选择发票来源：
   - **邮箱模式**：填写邮箱账号和应用专用密码；
   - **本地文件夹模式**：选择已经下载好 PDF 发票的文件夹，不需要邮箱账号。
5. 先执行预览；邮箱模式还可以先点“测试连接”。
6. 可选勾选“按购方公司整理原件”和“生成购方分表与金额汇总”。
7. 确认候选附件无误后，点击“确认执行”。

### macOS / Linux / 通用方式

```bash
python start.py
```

首次运行会自动安装 `pdfplumber` 和 `openpyxl`。本地向导只绑定 `127.0.0.1`，不会向局域网或公网开放。

## 使用前需要准备

- Python 3.10 或更高版本；
- 一个用于保存附件和 Excel 的本地目录；
- 如果使用邮箱模式：支持 IMAP 的邮箱、已开启 IMAP、邮箱生成的**应用专用密码**；
- 如果使用本地文件夹模式：一个已经放好发票附件的本地目录，无需邮箱权限。

常见邮箱预设已内置：QQ、163、Gmail、Outlook / Microsoft 365。企业邮箱可以选择“自定义”。不同邮箱开启 IMAP 和生成应用密码的方法可能变化，请以邮箱官方帮助中心为准。

## 安全设计

- 邮箱通过 IMAP 以 `readonly=True` 打开；程序不会发送、删除、移动、星标或修改邮件状态。
- 密码仅保存在当前浏览器表单和当前 Python 进程内存中，不写入 Excel、运行摘要或日志。
- 页面不使用 CDN、统计代码或第三方前端资源。
- 向导只接受 `localhost / 127.0.0.1` 请求，并使用随机会话令牌保护本地接口。
- 第一次正式运行前必须先预览候选附件。
- 重复发票默认保留并标记；无法确定的数据不会猜测填充。

> 设备若已被恶意软件控制，本地向导无法提供绝对安全保证。企业使用还应遵守内部邮箱权限、票据留存与数据合规规则。

## 输出内容

输出目录包含：

- `attachments/`：原始发票相关附件；
- `AI邮箱发票登记YYYYMMDD.xlsx`：登记表；
- `run-summary.json`：不含密码的运行统计。

基础 Excel 有三个工作表：

1. **发票汇总**：号码、日期、购销方、金额、税额、来源、解析状态和校验结果；
2. **项目明细**：可识别的商品或服务行项目；
3. **处理日志**：邮件来源、附件路径、哈希、状态及失败原因。

勾选财务增强后还会得到：

- `by_company/`：按购方公司复制归档的原始附件；
- `*_购方分表.xlsx`：保留三张基础表，并增加购方索引、统计口径和每家公司的独立分表；
- `buyer-summary.json`：购方分类、人工确认和文件完全重复副本统计。

去重采用保守规则：仅 SHA256 完全相同文件的后续副本不计入“建议合计”。号码重复但内容不同、号码缺失或购方不明的记录全部保留并提示人工确认，程序不会自动作出“不入账”决定。

## 当前边界

自动解析目标是带可选中文本层的增值税电子发票 PDF。以下文件会保留并标为“待人工处理”：

- 扫描 PDF；
- OFD、XML 和图片；
- 压缩包；
- 密码保护文件；
- 特殊版式或字段缺失的发票。

本工具不替代财务审核、报销审批、税务判断和最终入账。

## 自定义购方分类规则

复制 `rules/buyer-rules.example.json` 到仓库外的私有位置，修改为自己的公司别名和文件名映射，再在本地向导中选择该文件。真实规则文件可能包含公司与业务信息，默认不应提交 GitHub。

## 高级用户：命令行

```bash
python scripts/download_and_register.py \
  --config /secure/invoice-mail.env \
  --since 2026-08-01 \
  --until 2026-08-31 \
  --output-dir ./invoice-output \
  --dry-run
```

确认预览后移除 `--dry-run`。配置字段见 [`references/configuration.md`](references/configuration.md)。

## 测试

```bash
python -m unittest discover -s tests -v
python -m py_compile scripts/download_and_register.py scripts/buyer_organizer.py scripts/setup_wizard.py start.py
```

测试不连接真实邮箱，也不使用真实账号或发票。
